# REKA QUEST AI — Gemini Edition

## Setup Windows
1. Pastikan Node.js telah dipasang.
2. Buka Command Prompt dalam folder projek.
3. Jalankan:
   npm install
4. Salin `.env.example` dan namakan salinan itu `.env`.
5. Buka `.env` dan masukkan Gemini API key anda:
   GEMINI_API_KEY=...
6. Jalankan:
   npm start
7. Buka:
   http://localhost:3000

Model lalai: gemini-3.8-flash

PENTING:
- Jangan letakkan Gemini API key di dalam `public/index.html`.
- Jangan kongsi fail `.env`.
- Free tier mempunyai had penggunaan.
- Elakkan menghantar data peribadi sensitif murid ke API.
